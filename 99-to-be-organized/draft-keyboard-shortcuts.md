## Overview

Keyboard shortcuts make you dramatically faster in VS Code. You don't need to memorize all of them — start with the essentials and add more as you get comfortable.

## The Absolute Essentials (Start Here)

These 10 shortcuts will cover 80% of your daily needs:

| Action | Windows | Mac | Why It's Essential |
| ------ | ------- | --- | ------------------ |
| **Open Command Palette** | `Ctrl+Shift+P` | `Cmd+Shift+P` | Access ANY VS Code command by typing |
| **Quick Open (find file)** | `Ctrl+P` | `Cmd+P` | Jump to any file instantly |
| **Save** | `Ctrl+S` | `Cmd+S` | Save current file |
| **Save All** | `Ctrl+K S` | `Cmd+Option+S` | Save all open files |
| **Undo** | `Ctrl+Z` | `Cmd+Z` | Undo last action |
| **Redo** | `Ctrl+Y` | `Cmd+Shift+Z` | Redo undone action |
| **Find** | `Ctrl+F` | `Cmd+F` | Search in current file |
| **Find in Files** | `Ctrl+Shift+F` | `Cmd+Shift+F` | Search across ALL files |
| **Toggle Sidebar** | `Ctrl+B` | `Cmd+B` | Show/hide the left sidebar |
| **Open Copilot Chat** | `Ctrl+Alt+I` | `Cmd+Option+I` | Start chatting with Copilot |

## The Command Palette: Your Secret Weapon

The **Command Palette** (`Ctrl+Shift+P` / `Cmd+Shift+P`) is the most powerful shortcut because it gives you access to EVERY command in VS Code.

### How to Use It

1. Press `Ctrl+Shift+P`
2. Start typing what you want to do (e.g., "format document")
3. Select from the filtered list
4. Press Enter

### Examples

| Type This... | To Do This... |
| ------------ | ------------- |
| `format` | Format the current document |
| `theme` | Change your color theme |
| `font` | Change font size |
| `reload` | Reload the VS Code window |
| `keyboard` | Open keyboard shortcuts settings |
| `copilot` | See all Copilot commands |

> [!TIP]
> If you forget a shortcut, just open the Command Palette and type what you want to do!

## Customize Your Shortcuts

Don't like a shortcut? Change it!

1. Press `Ctrl+K Ctrl+S` (or `Cmd+K Cmd+S` on Mac)
2. Search for the command you want to change
3. Click the pencil icon next to it
4. Press your preferred key combination
5. Press Enter to save
