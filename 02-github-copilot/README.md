# 🤖 GitHub Copilot - AI Assistance in VS Code

GitHub Copilot is an AI-powered assistant that lives inside VS Code (and other code editors). If VS Code is your workspace, Copilot is like a smart pair programmer or writing assistant that's with you in that workspace.

It was developed by GitHub and OpenAI to help write code, but you can also think of it as a **text generator that understands code context**.
